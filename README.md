# Company Verify

Plugin do weryfikacji firm i kontrahentów w oficjalnych rejestrach (KRS, CEIDG, biała lista VAT, CRBR – beneficjenci rzeczywiści, VIES, GLEIF, Companies House oraz rejestry zagraniczne) z dokumentów lub danych rejestrowych.

## Import do Perplexity

1. Otwórz Perplexity i przejdź do **Plugins** w pasku bocznym (lub **Customize → Connectors and Skills**).
2. Kliknij **Add custom** → **Import plugin from GitHub**.
3. Wklej adres repozytorium:
   ```text
   https://github.com/MarmoPL/company-verify
   ```
4. Zatwierdź import skilla `weryfikacja-firmy`.
